FileCleanup 绿色版 · 使用说明
================================================

【怎么开始】
1. 双击 FileCleanup.exe（首次会弹出控制台窗口，里面会显示本机访问地址）
2. 浏览器会自动打开 http://127.0.0.1:8770 ；没自动打开就手动复制这个地址
3. 在页面上方填要扫描的目录（或用「快速选择」挑盘符 / 下载目录），点「开始扫描」
4. 用完点页面右上角的「退出」，程序会关闭服务、释放端口并结束进程
   （也可以在控制台窗口按 Ctrl+C；直接关浏览器页面不会停服务）

【不需要什么】
- 不需要安装 Python
- 不需要配置环境变量
- 不需要联网（所有资源都在本目录内）
- 路径可以随便放，中文目录名也没问题

【换电脑 / 拷给别人】
把整个 FileCleanup 文件夹（含 FileCleanup.exe 和 _internal 文件夹）一起拷贝，
可以压成 zip 传，解压后双击 exe 就能用。注意：
- 只拷 exe 不拷 _internal 会启动失败
- 目标电脑需为 Windows 64 位（Windows 10 及以上）
- 极老的系统若提示缺少 api-ms-win-*.dll / VCRUNTIME，装一次
  「Microsoft Visual C++ 运行库」即可

【端口】
默认 8770。如果被别的程序占用，会自动顺延到 8771、8772…，以窗口里显示的地址为准。

【安全相关】
- 只监听 127.0.0.1，外部电脑访问不到
- 删除默认是送系统回收站，可撤销；回收站失败时不会擅自改成永久删除
- 只能删除本次扫描结果里的条目，且路径必须在扫描根目录之下
- 杀毒软件可能误报 unknown publisher（自打包程序没有数字签名），
  选「允许运行 / 添加到信任」即可；介意的话可用源码方式运行（python run.py）

【几个实用操作】
- 单击节点：展开 / 折叠
- 双击节点：在资源管理器里定位该文件 / 文件夹
- 右键节点：定位 / 加入清理清单 / 复制路径 / 展开或折叠全部子级
- 滚轮缩放、按住拖拽平移；f 键适应窗口，c 键全部折叠，/ 键聚焦搜索框
- 右上角 🌙/☀️ 切换深色 / 浅色主题；? 查看全部快捷键

【扩展名中文释义】
想补充或修改扩展名释义：编辑 _internal/resources/ext_zh.json，
或在 C:\Users\<用户名>\.filecleanup\ext_zh.json 里放同名条目做个人覆盖，重启生效。
